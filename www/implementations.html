AuthZEN implementations: PDPs, gateways and IdPs

By David Brossard · Last updated 3 November 2026

A directory of products and open-source projects that implement the OpenID AuthZEN Authorization API, either as a PDP (decision point that answers AuthZEN requests) or as a PEP (enforcement point such as an API gateway, IdP or application that calls one).

Missing or out of date? Open an issue with a link to public documentation.

Interop results

The working group runs public interops where PEPs and PDPs from different vendors exercise the same test suite, including at Identiverse 2024 and Gartner IAM. Interop rounds have covered the evaluation API, the Search APIs, API gateways and IdP integrations.
